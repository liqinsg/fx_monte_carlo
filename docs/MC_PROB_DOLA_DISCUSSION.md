## 二、基本概念定义

| 术语     | 符号           | 说明                                                       |
| -------- | -------------- | ---------------------------------------------------------- |
| 状态空间 | $\Omega$     | 当前分析范围内所有可能市场状态集合                         |
| 先验概率 | $P(S_i)$     | 基于历史数据，状态$S_i$发生的基础概率，$\sum P(S_i)=1$ |
| 似然度   | $P(E | S_i)$ |                                                            |
| 后验概率 | $P(S_i | E)$ |                                                            |
| 置信阈值 | $\tau$       | 后验概率达到该值时，判定状态并触发对应判断                 |
| 证据概率 | $(P(E))$     | $(P(E))=\sum_i P(E                                         |

> 常用状态示例：$S_1$=上涨、$S_2$=下跌、$S_3$=震荡

## 三、标准标注字段

每条记录统一使用以下固定格式：

```
【ID】         日期+序号
【时间/周期】   YYYY-MM-DD HH:MM | K线周期
【证据E】       观测信号、指标形态或价格行为描述
【先验分布】    P(S₁)=xx, P(S₂)=xx, P(S₃)=xx
【似然矩阵】    P(E|S₁)=xx, P(E|S₂)=xx, P(E|S₃)=xx
【后验计算】    代入公式 → P(S₁|E)=xx, P(S₂|E)=xx, P(S₃)=xx
【置信判定】    是否≥阈值\(\tau\) → 倾向S₁/S₂/S₃ / 暂不判定
【备注】        数据来源、假设条件、异常说明、更新记录
```

---

## 四、概率更新机制

- **初始化**：基于历史统计设定初始先验；随周期滚动持续更新分布
- **多证据叠加**：证据间独立时链式更新

$$
P(S_i|E_1,E_2)=\frac{P(E_2|S_i)\cdot P(S_i|E_1)}{\sum_j P(E_2|S_j)\cdot P(S_j|E_1)}
$$

- **时效性处理**：随时间推移或新增矛盾证据，后验概率合理回落，避免判断固化

## 五、标注示例

```
【ID】         20261117-01
【时间/周期】   2026-11-17 08:30 | H1
【证据E】       RSI=42，未超买超卖；价格站上短期均线
【先验分布】    P(上涨)=0.40, P(下跌)=0.35, P(震荡)=0.25
【似然矩阵】    P(E|上涨)=0.70, P(E|下跌)=0.30, P(E|震荡)=0.50
【后验计算】    \(P(E)\)=0.40×0.70+0.35×0.30+0.25×0.50=0.51
               P(上涨|E)=0.70×0.40÷0.51=0.549
               P(下跌|E)=0.30×0.35÷0.51=0.206
               P(震荡|E)=0.50×0.25÷0.51=0.245
【置信判定】   \(\tau\)=0.60，最高后验0.549<阈值 → 暂不判定，保持中性
【备注】        证据偏弱，等待成交量/突破确认；先验基于近30日H1统计
```
